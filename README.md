# Tenor Saxophone Beginner Studio

Interactive beginner PWA for tenor saxophone:

- Fingerings from written low Bb through high F#
- Written-pitch scales, modes, and arpeggios
- BPM player (slider + number box)
- Add to iPhone Home Screen from Safari

## Live app (after GitHub Pages is on)

1. Repo **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main`, folder: `/ (root)`
4. Open:

`https://briansamuelbaker.github.io/Tenor-Sax-/tenor-sax-beginner.html`

On iPhone: Safari → Share → Add to Home Screen.

## Files

- `tenor-sax-beginner.html` — app
- `index.html` — redirects to the app
- `manifest.json` — PWA name, icon, standalone display
- `sw.js` — service worker (offline cache)
- `sax-icon.svg` — Home Screen icon
